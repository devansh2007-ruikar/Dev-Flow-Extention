# DevFlow Extension 🚀

**Automate Google Flow at Scale — Generate Images, Videos, Avatars, and More with Bulk Prompts**

DevFlow is a powerful browser extension designed for creators, marketers, agencies, and AI enthusiasts who need to generate large volumes of content using Google Flow. Instead of manually entering prompts one by one, DevFlow allows you to submit hundreds of prompts at once and automate your entire workflow.

---

## ✨ Features

### 🔥 Bulk Prompt Processing

Generate content from **hundreds or even thousands of prompts** without manually entering each one.

* Paste bulk prompts in a single operation
* Queue unlimited prompt lists
* Save hours of repetitive work
* Perfect for large-scale content production

### 🎥 Prompt-to-Video Generation

Automatically process multiple text prompts into videos through Google Flow.

### 🖼️ Prompt-to-Image Generation

Create large batches of AI-generated images from bulk prompts.

### 🖼️➡️🎥 Image-to-Video Workflow

Convert images into videos at scale without repetitive manual input.

### 🖼️➡️🖼️ Image-to-Image Generation

Run image transformation workflows in bulk.

### 🤖 AI Avatar Support

Integrate AI avatars into your content generation pipeline.

### 🎙️ AI Voice Integration

Add AI-generated voiceovers and narration to your projects.

### 📂 Organized Bulk Downloads

Download all generated content automatically.

* Downloads are saved in folders named according to your project
* Files maintain the exact sequence of submitted prompts
* Easy content management and organization
* No need to manually rename files

### ⚡ Workflow Automation

Reduce repetitive tasks and focus on creating content rather than managing prompts.

## 🚀 Why DevFlow?

Manually generating content in Google Flow becomes slow and inefficient when working with large prompt libraries.

DevFlow solves this by:

* Automating repetitive actions
* Supporting bulk prompt execution
* Maintaining prompt order and file organization
* Enabling scalable AI content generation
* Saving significant time and effort

## 🛠️ How It Works

1. Install the DevFlow Extension.
2. Open Google Flow.
3. Paste your bulk prompt list.
4. Choose your workflow:

   * Prompt to Video
   * Prompt to Image
   * Image to Video
   * Image to Image
5. Start automation.
6. Let DevFlow process all prompts automatically.
7. Download generated files in organized folders with preserved sequence order.
